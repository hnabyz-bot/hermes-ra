## 🔍 GLM 문제 진단 및 해결

### 근본 원인 분석

**Cycle 1 증상**: GLM은 `/analyze` 기본 분석은 성공(652 chars)하지만 `wp_comment` 생성에서 0 bytes 반환

**로그 시퀀스**:
```
[debug] GLM calling glm-4.5-air...
[debug] glm raw response: 652 chars ✅ (첫 번째 호출 - 성공)
[debug] GLM calling glm-4.5-air...
[debug] GLM success: 0 chars ❌ (두 번째 호출 - wp_comment 실패)
[warn] GLM wp_comment 실패
```

**근본 원인**: z.ai API의 `max_tokens` 한도 초과로 인한 빈 응답 반환

### 해결 (2026-05-10)

| 항목 | 변경 전 | 변경 후 |
|------|--------|--------|
| 프롬프트 길이 | 1,097 chars | 719 chars (-34.5%) |
| max_tokens | 1,500 | 3,000 |
| NAS 문서 참조 | 제한 없음 | 최대 3개 |
| 첨부파일 본문 | 제한 없음 | 최대 800자 |

**결과**: GLM 응답 정상화 (1,325자), Cycle 3 재평가 **45/45 만점**
